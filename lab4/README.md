# Лабораторная работа: 3D Gallery GLB

В данной папке находится реализация 3D-галереи моделей формата GLB.

Выполненная работа:

- создана страница галереи с карточками 3D-моделей;
- реализованы canvas-превью моделей через Three.js и GLTFLoader;
- добавлена страница детального просмотра модели;
- в детальном просмотре реализованы вращение, масштабирование и быстрые ракурсы камеры;
- добавлена загрузка пользовательских `.glb`/`.gltf` файлов;
- пользовательские модели сохраняются в IndexedDB браузера;
- предусмотрена fallback-отрисовка, если модель не загрузилась.

Основные файлы:

- `gallery.html` — страница галереи;
- `gallery.js` — логика карточек и 3D-превью;
- `model-detail.html` — страница просмотра одной модели;
- `model-detail.js` — управление камерой и загрузка модели;
- `idb.js` — работа с IndexedDB;
- `site.css` — оформление.

Лабораторная демонстрирует работу с WebGL/Three.js, загрузку 3D-моделей и локальное хранение пользовательских данных в браузере.
