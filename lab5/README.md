# Лабораторная работа 5: AJAX-запросы к API

В данной папке выполнена лабораторная работа по взаимодействию клиентской части с API через `XMLHttpRequest`.

Предметная область: производство кораблей.

Выполненная работа:

- реализован Express API `/stocks` с карточками корабельных классов;
- создан слой `modules/ajax.js` для HTTP-запросов через `XMLHttpRequest`;
- создан слой `modules/stockUrls.js` для централизованного хранения URL API;
- главная страница получает список карточек через `GET /stocks`;
- реализован фильтр по названию карточки через query-параметр `GET /stocks?title=...`;
- детальная страница получает карточку через `GET /stocks/:id`;
- добавлено удаление карточки через `DELETE /stocks/:id`;
- сервер отдает клиентскую часть и API на одном порту.

Основные файлы:

- `index.html`, `main.js` — клиентская часть;
- `modules/ajax.js` — AJAX-слой;
- `modules/stockUrls.js` — URL-слой;
- `pages/`, `components/` — страницы и компоненты интерфейса;
- `src/index.js` — запуск Express-сервера;
- `src/routes/stocks.js` — маршруты API;
- `src/controllers/stocksController.js` — контроллеры;
- `src/services/` — бизнес-логика и работа с файлом;
- `src/data/stocks.json` — данные карточек.

Проверка лабораторной выполняется запуском сервера командой `npm run start` и открытием `http://localhost:3000`. Во вкладке Network видны запросы к `/stocks`.
