# Лабораторная работа 6: Promise, fetch и сборка клиентской части

В данной папке выполнена лабораторная работа по замене `XMLHttpRequest` на `fetch` и сборке клиентской части через Vite.

Предметная область: производство кораблей.

Выполненная работа:

- сетевые запросы переведены на `fetch`;
- для асинхронного кода используется `async/await`;
- создан модуль `modules/api.js`, инкапсулирующий GET, POST, PATCH и DELETE запросы;
- сохранен модуль `modules/stockUrls.js` для централизованной работы с URL;
- главная страница получает карточки через `GET /stocks`;
- фильтр по названию использует query-параметр `GET /stocks?title=...`;
- детальная страница получает карточку через `GET /stocks/:id`;
- удаление карточки выполняется через `DELETE /stocks/:id`;
- настроена сборка клиентской части через Vite;
- собранная клиентская часть помещается в папку `public`;
- Express-сервер раздает собранный фронтенд как статические файлы и обслуживает API.

Основные файлы:

- `modules/api.js` — слой запросов на `fetch`;
- `pages/`, `components/` — клиентская логика приложения;
- `vite.config.js` — конфигурация сборки;
- `public/` — результат сборки клиентской части;
- `src/index.js` — Express-сервер и раздача статики;
- `src/data/stocks.json` — данные карточек.

Проверка лабораторной выполняется командами `npm run build` и `npm run start`. После запуска сервер доступен по адресу `http://localhost:3000`, клиентская часть загружается из сборки, а API доступно по маршрутам `/stocks`.
