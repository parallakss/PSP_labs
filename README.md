## Ветки работ

Лабораторные и домашнее задание хранятся в отдельных ветках:

- `lab1` — лабораторная работа 1;
- `lab2` — лабораторная работа 2;
- `lab3` — лабораторная работа 3;
- `lab4` — лабораторная работа 4;
- `lab5` — лабораторная работа 5;
- `lab6` — лабораторная работа 6;
- `homework` — домашнее задание.

Ветка `main` используется только как навигационная страница репозитория.
