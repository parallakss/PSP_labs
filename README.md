# PSP Labs

Репозиторий с лабораторными работами по теме судостроительной программы и производства кораблей.

## Ветки лабораторных работ

Лабораторные работы хранятся в отдельных ветках, а не в `main`:

- `lab1` — калькулятор;
- `lab2` — основной сайт по теме производства кораблей;
- `lab3` — компонентное веб-приложение;
- `lab4` — 3D-галерея моделей кораблей;
- `lab5` — AJAX / XMLHttpRequest и Express API;
- `lab6` — fetch, async/await, Vite и Express API.

## Как открыть нужную лабораторную

```bash
git checkout lab1
```

или для другой работы:

```bash
git checkout lab5
```

В каждой ветке находится только соответствующая папка лабораторной работы и необходимые общие файлы.

## Дополнительно

Папка `homework1_js/` оставлена отдельно, так как относится к домашнему заданию, а не к лабораторным веткам.
