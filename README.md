# PSP Labs

Репозиторий с лабораторными работами по теме судостроительной программы и производства кораблей.

## Структура веток

Основные лабораторные работы вынесены в отдельные ветки:

- `lab1` — калькулятор;
- `lab2` — основной сайт по теме производства кораблей;
- `lab3` — компонентное веб-приложение;
- `lab4` — 3D-галерея моделей кораблей;
- `lab5` — AJAX / XMLHttpRequest и Express API;
- `lab6` — fetch, async/await, Vite и Express API.

Ветка `main` используется как навигационная ветка и не является основным местом хранения всех лабораторных работ.

## Текущая рабочая структура

В рабочей копии лабораторные приведены к единому виду:

```text
lab1/
lab2/
lab3/
lab4/
lab5/
lab6/
homework1_js/
```

Каждая лабораторная содержит собственный `README.md` с кратким описанием выполненной работы и инструкцией по запуску, если запуск требует дополнительных действий.
