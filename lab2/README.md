## 1. Программирование логики с помощью JavaScript

Язык программирования JavaScript служит основным инструментом для описания логики и интерактивности веб-страниц. В данной работе с помощью JS мы будем программировать кнопки калькулятора, чтобы они работали.

### Как подключить JavaScript к HTML?

Есть два способа добавить JavaScript на веб-страницу:

1. **Встроенный скрипт** - когда код пишется прямо в HTML-файле внутри тега `<script>`:
```html
<script>
    // Здесь пишем JavaScript код
    console.log("Привет, мир!");
</script>
```

2. **Внешний файл** - когда код хранится в отдельном файле с расширением .js:
```html
<head>
    <title>калькулятор</title>
    <link rel="stylesheet" href="style.css">
    <script type="text/javascript" src="script.js"></script>
</head>
```

Для нашего калькулятора мы будем использовать второй способ, так как это более организованный подход.

## 2. Доступ к HTML-элементам из JavaScript

Чтобы управлять элементами на странице, нам нужно сначала получить к ним доступ. JavaScript предоставляет несколько способов это сделать:

### Основные методы получения элементов:

1. **По ID** (метод `getElementById`) - самый распространенный способ:
```html
<body>
    <p id="paragraph" className="textRed">Lorem Ipsum</p>

    <!--вложенный JS-скрипт-->
    <script>
    <!-- обращаемся к HTML-документу и ищем объект с id=paragraph -->
        element = document.getElementById("paragraph")

        <!-- через свойство innerHTML у полученного объекта можно изменить его содержимое-->
        element.innerHTML = "Измененный текст параграфа";
    </script>
</body>
```

2. **По тегу** - получаем все элементы определенного типа:
```js
// Получить все параграфы на странице
let paragraphs = document.getElementsByTagName("p")
```

3. **По классу** - получаем все элементы с определенным классом:
```js
// Получить все элементы с классом "button"
let buttons = document.getElementsByClassName("textRed")
```

### Обработчики событий - это функции, которые будут вызываться при совершении какого-либо события.

В нашем случае мы обрабатываем событие нажатия на кнопку - то есть `click`.
Способы задания обработчиков событий:

1. **Через атрибут HTML (inline-обработчик):**
```html
<button onclick="alert('Кнопка нажата!')">Нажми меня</button>
```

2. **Через свойство элемента (как в нашем калькуляторе):**
```js
element.onclick = function() {
    alert('Кнопка нажата!');
}
```

3. **Через метод addEventListener (современный способ):**
```js
element.addEventListener('click', function() {
    alert('Кнопка нажата!');
});
```

В нашем калькуляторе мы используем второй способ (через свойство `onclick`), так как для каждой кнопки нам нужен только один обработчик, и это делает код более простым и понятным.

### Шаг 2: Получение доступа к элементам калькулятора
```js
    const outputElement = document.getElementById("result")
    const digitButtons = document.querySelectorAll('[id ^= "btn_digit_"]')
```
Селектор `[id ^= "btn_digit_"]` находит все элементы, id которых начинается с текста `"btn_digit_"`.

### Шаг 3: Функция обработки нажатия на цифровые кнопки
```js
    function onDigitButtonClicked(digit) {
        if (!selectedOperation) {
            if ((digit != '.') || (digit == '.' && !a.includes(digit))) {
                a += digit;
            }
            outputElement.innerHTML = a;
        } else {
            if ((digit != '.') || (digit == '.' && !b.includes(digit))) {
                b += digit;
                outputElement.innerHTML = b;
            }
        }
    }
```

### Шаг 4: Настройка обработчиков событий
```js
    digitButtons.forEach(button => {
        button.onclick = function() {
            const digitValue = button.innerHTML;
            onDigitButtonClicked(digitValue);
        }
    });
```

## 6. Выполненные дополнительные задания

В ходе выполнения второй лабораторной работы был реализован следующий дополнительный функционал на JavaScript:

### 1. Операция смены знака (+/-)
При нажатии на кнопку `+/-` текущее значение умножается на `-1`.
```javascript
document.getElementById("btn_op_sign").onclick = function() {
    const cur = getCurrentNumber();
    updCur = -1 * cur;
    a = updCur;
    updateDisplay(updCur);
}
```

### 2. Операция вычисления процента (%)
Позволяет вычислить процентное отношение текущего числа.
```javascript
document.getElementById("btn_op_percent").onclick = function() {
    if (a === '') return;
    if (b !== '') {
        calculateResult();
    }
    selectedOperation = '%';
    historyElement.innerHTML += a + '%';
}
```
Расчет в функции `calculateResult`:
```javascript
case '%':
    expressionResult = (+a) / 100 * (+b);
    break;
```

### 3. Добавление трех нулей (000)
В HTML добавлена кнопка `<button id="btn_digit_000" class="my-btn">000</button>`. Поскольку её ID начинается с `btn_digit_`, она автоматически обрабатывается циклом `digitButtons.forEach`, добавляя к текущему числу сразу три нуля как строку.

### 4. Накапливаемое сложение (A+) и вычитание (A-)
Реализована работа с промежуточным аккумулятором через кнопки `A+` и `A-`. Переменная `accumulator` сохраняет промежуточный итог вычислений, который сразу выводится на экран.
```javascript
document.getElementById('btn_op_accplus').onclick = function () {
    const cur = getCurrentNumber();
    if (cur === '') return;
    accumulator += +cur;
    a = accumulator.toString(); b = '';
    updateDisplay(a);
}

document.getElementById('btn_op_accminus').onclick = function () {
    const cur = getCurrentNumber();
    if (cur === '') return;
    accumulator -= +cur;
    a = accumulator.toString(); b = '';
    updateDisplay(a);
}
```

### 5. Индивидуальная операция: обратное число (1/x)
Добавлена кнопка, вычисляющая значение `1/x` для текущего введенного числа. Предусмотрена защита от деления на ноль с выводом сообщения "Ошибка" в окно калькулятора и "деление на 0" в историю.
```javascript
document.getElementById('btn_op_custom').onclick = function () {
    const cur = getCurrentNumber();
    if (cur === '' || +cur === 0) {
        outputElement.innerHTML = 'Ошибка';
        historyElement.innerHTML = 'деление на 0';
        return;
    }
    a = (1 / +cur);
    updateDisplay((1 / +cur).toString());
};
```

### 6. Панель истории вычислений
Создан HTML-блок `<div id="historyArea" class="history-panel"></div>`, в который динамически записываются все вводимые числа и операции. Для его очистки при нажатии на `C` добавлена вспомогательная функция `clearHistory()`.

### 7. Ограничение длины вывода и форматирование (Защита от переполнения экрана)
Чтобы предотвратить выход огромных чисел за границы экрана, реализована функция `limitDisplayLength`. Она обрезает строку до `MAX_DISPLAY_LENGTH = 9`, добавляя символ экспоненты `e` и оставшуюся длину.
Дополнительно при вводе используется регулярное выражение `a.replace(/^0+/, '')` для автоматического удаления лишних ведущих нулей.
