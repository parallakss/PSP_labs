# Лабораторная работа: сайт по теме производства кораблей

В данной папке находится тематический сайт судостроительного производственного комплекса.

Выполненная работа:

- сайт адаптирован под тему производства кораблей и государственных заказов;
- добавлены основные разделы: производство, услуги, калькулятор, заявки, контакты;
- реализованы карточки классов кораблей: патрульные корабли, фрегаты, суда снабжения;
- при выборе карточки открывается модальное окно с расширенным описанием выбранного класса;
- встроен калькулятор как часть сайта, без перехода на отдельный ресурс;
- добавлен блок контактов с телефоном и ссылкой на GitHub.

Основные файлы:

- `index.html` — структура сайта;
- `site.css` — визуальное оформление;
- `script.js` — логика модальных окон и калькулятора;

Результат соответствует выбранной предметной области: сайт описывает производственные возможности судостроительного комплекса и классы кораблей для государственных заказов.
