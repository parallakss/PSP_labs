# Лабораторная работа: калькулятор

В данной папке представлена реализация веб-калькулятора на HTML, CSS и JavaScript.

Выполненная работа:

- сверстана отдельная страница калькулятора;
- реализован ввод чисел и десятичной точки;
- реализованы арифметические операции сложения, вычитания, умножения и деления;
- добавлены дополнительные операции: процент, смена знака, квадратный корень, квадрат числа, факториал;
- добавлены служебные действия: очистка, удаление последнего символа, ввод `000`;
- реализовано повторное применение последней операции через `=`;
- добавлено переключение светлой/темной темы.

Основные файлы:

- `calculator.html` — структура интерфейса калькулятора;
- `style.css` — оформление калькулятора и тем;
- `script.js` — обработчики кнопок и логика вычислений.

Проверка работы выполняется открытием `calculator.html` в браузере. Все вычисления выполняются на клиентской стороне без перезагрузки страницы.
