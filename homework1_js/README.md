# Домашнее задание 1: задачи на JavaScript

В данной папке находится решение домашнего задания по циклам, массивам, коллекциям и объектам в JavaScript.

Исходные данные варианта:

- первая буква фамилии: `Ж`;
- первая буква имени: `И`;
- группа: `ИУ5-46Б`.

Выполненные задания:

- `1.1` — функция `concatenate`, склеивание массива строк через разделитель;
- `1.5` — функция `moveElement`, перемещение элемента массива;
- `2.5` — функция `findCouple`, поиск пар целых чисел с заданной суммой;
- `3.1` — функция `merge`, объединение объектов с сохранением первого значения поля;
- `3.2` — функция `inverse`, изменение порядка элементов массива с учетом второго аргумента;
- `3.3` — функция `flatten`, преобразование вложенных массивов в плоский массив;
- `3.4` — функция `sort`, сортировка букв в словах и слов в предложении;
- `3.5` — функция `anagram`, группировка слов-анаграмм;
- `3.6` — функция `rle`, RLE-сжатие строки.

Основной файл:

- `hw1_part1.js` — реализации функций и проверочные вызовы `console.log`.

Решения проверяются запуском файла через Node.js. Проверочные вызовы демонстрируют корректность работы функций на примерах.
