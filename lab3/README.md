# Лабораторная работа: компонентное веб-приложение

В данной папке сохранена компонентная структура приложения, выполненная по методике разделения интерфейса на страницы и переиспользуемые компоненты.

Выполненная работа:

- создана точка входа `main.js`;
- код разделен на страницы в папке `pages`;
- переиспользуемые элементы вынесены в папку `components`;
- реализована главная страница со списком карточек;
- реализован переход на страницу выбранной карточки;
- добавлена кнопка возврата на главную страницу;
- компоненты принимают данные через параметры и отвечают за собственную отрисовку.

Структура:

- `main.js` — инициализация приложения;
- `pages/main/index.js` — главная страница;
- `pages/product/index.js` — страница выбранной карточки;
- `components/product-card/index.js` — карточка в списке;
- `components/product/index.js` — детальное отображение карточки;
- `components/back-button/index.js` — кнопка возврата.

Папка демонстрирует переход от монолитной HTML-страницы к модульной архитектуре фронтенда.
