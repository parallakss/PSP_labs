## 1. Модули и классы в JavaScript

Современный стандарт JavaScript (ES6) позволяет разделять монолитный код на независимые блоки — модули. Это фундаментальный подход в современной веб-разработке, который решает сразу несколько проблем:
* **Изоляция области видимости:** переменные внутри модуля не засоряют глобальную область видимости (`window`), что исключает конфликты имен.
* **Переиспользуемость:** один и тот же компонент (например, кнопку или карточку) можно импортировать в разные части приложения.
* **Удобство поддержки:** логика разделена по файлам строго в соответствии с их назначением.

Для работы с модулями используются ключевые слова `export` (экспорт сущности наружу) и `import` (загрузка сущности в текущий файл). Чтобы браузер понимал, что мы используем модульную систему, главный скрипт подключается в HTML со специальным атрибутом `type="module"`:

```html
<!-- Подключение главного файла логики -->
<script src="main.js" type="module"></script>
```

Для описания логики UI-элементов используются ES6 классы. Каждый класс инкапсулирует данные и методы конкретного компонента.

```javascript
export class ExampleComponent {
    constructor(parent) {
        this.parent = parent; // родительский HTML-контейнер
    }
    render() {
        this.parent.innerHTML = `<div>Привет, я компонент!</div>`;
    }
}
```

## 2. Архитектура проекта

Проект разделен на логические слои. Папки и файлы организованы следующим образом:

- **`add/main.html`** — Точка входа. Содержит статический контент (шапку, подвал) и пустой контейнер `<div id="root"></div>`, куда JS будет динамически загружать страницы.
- **`add/main.js`** — Главный скрипт инициализации. Находит `#root` и вызывает рендер Главной страницы.
- **`add/pages/`** — Содержит классы страниц (например, `MainPage`, `ProductPage`).
- **`add/components/`** — Содержит переиспользуемые элементы интерфейса (например, `ProductCardComponent`, `AlertComponent`).

Инициализация приложения в `main.js`:
```javascript
import { MainPage } from './pages/main/index.js';

document.addEventListener("DOMContentLoaded", () => {
    const rootElement = document.getElementById('root');
    if (rootElement) {
        const mainPage = new MainPage(rootElement);
        mainPage.render();
    }
});
```

## 3. Рендеринг компонентов

Отрисовка элементов происходит с использованием шаблонных строк (Template literals) с интерполяцией `${...}`.

Например, карточка классов кораблейи в кораблестроительное производствое (`ProductCardComponent`):
```javascript
export class ProductCardComponent {
    constructor(parent) { this.parent = parent; }

    getHTML(data) {
        return `
            <div class="card bg-dark text-light">
                <img src="${data.src}" class="card-img-top">
                <div class="card-body">
                    <h5 class="card-title">${data.name}</h5>
                    <p class="card-text">${data.description}</p>
                    <button id="open-btn-${data.id}">Подробнее</button>
                </div>
            </div>
        `;
    }

    render(data, openListener) {
        // Добавляем HTML в конец родительского контейнера
        this.parent.insertAdjacentHTML('beforeend', this.getHTML(data));
        // Вешаем слушатель события на свежесозданную кнопку
        document.getElementById(`open-btn-${data.id}`).addEventListener("click", openListener);
    }
}
```
Такой подход (генерация HTML-строки и последующее добавление обработчиков через `addEventListener`) является базовым принципом работы UI-компонентов.

## 4. Навигация между страницами

В одностраничных приложениях (SPA) переход по ссылкам не перезагружает страницу полностью. Вместо этого JavaScript очищает содержимое родительского контейнера и вызывает `render()` у другой страницы.

Пример перехода с главной страницы на детальную страницу продукта (`ProductPage`):
```javascript
clickCard(e) {
    // Находим ID кликнутого элемента
    const id = e.target.dataset.id;
    // Ищем нужные данные в массиве
    const item = this.getData().find(item => item.id == id);
    // Создаем экземпляр новой страницы, передавая тот же родительский контейнер (#root)
    const page = new ProductPage(this.parent, item);
    // Отрисовываем новую страницу
    page.render();
}
```
В методе `render()` новой страницы мы сначала полностью перезаписываем контейнер `this.parent.innerHTML = ...`, стирая предыдущую страницу, а затем вешаем обработчик для кнопки "Назад", который делает обратное действие — снова рендерит `MainPage`.

## 5. Реализованный функционал и дополнительные задания

В рамках данной лабораторной работы была создана SPA-архитектура на тему **Кораблестроительного производства «кораблестроительное производство»**, адаптированная под уникальный стиль и требования:

### 1. Тематический контент и Bootstrap-верстка
Метод `getData()` главной страницы возвращает массив классов кораблей (патрульные корабли, фрегаты, Балансировщики нагрузки). Классы Bootstrap интегрированы в `getHTML()`, создавая адаптивную сетку карточек (`d-flex flex-wrap justify-content-center gap-4`).

### 2. Динамические страницы классов кораблей (`ProductPage`)
При нажатии кнопки «Подробнее» вызывается переход на детальную страницу выбранной классов кораблейи. Она содержит увеличенное изображение, детальное описание и кнопку «← Вернуться к классов кораблейам» для реализации SPA-навигации.

```javascript
clickBack() {
    const page = new MainPage(this.parent);
    page.render();
}
```

### 3. Компонент всплывающих уведомлений (`AlertComponent`)
Был реализован сложный компонент уведомлений (Alerts), отвязанный от основной сетки сайта.
Особенности:
* Автоматическое создание плавающего контейнера (`#alerts-container`) поверх остального контента (`position-fixed`).
* Автоматическое исчезновение через 4 секунды с использованием таймера `setTimeout`.
* Кнопка закрытия внутри самого уведомления.
* **Ограничение количества уведомлений:** на экране может быть не более 4 всплывающих окон одновременно. При появлении 5-го самое старое окно автоматически удаляется.

```javascript
// Логика удаления старого алерта при превышении лимита
const currentAlerts = this.container.querySelectorAll('.alert');
if (currentAlerts.length >= 4) {
    currentAlerts[0].remove();
}
```

### 4. Контекст исполнения (bind)
Для того чтобы методы класса не теряли контекст (то есть `this` по-прежнему ссылался на сам класс, а не на HTML-элемент, по которому кликнули), активно используется метод `bind(this)`.

```javascript
this.getData().forEach(cat => {
    const card = new ProductCardComponent(this.pageRoot);
    card.render(
        cat,
        this.clickCard.bind(this),
        this.showAlert.bind(this)
    );
});
```
