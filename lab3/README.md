# Лабораторная работа 3: компонентное веб-приложение и 3D-галерея

В данной папке сохранена компонентная структура приложения, выполненная по методике разделения интерфейса на страницы и переиспользуемые компоненты. Работа адаптирована под тему судостроительной программы.

## Выполненная работа

- создана точка входа `main.js`;
- код разделен на страницы в папке `pages`;
- переиспользуемые элементы вынесены в папку `components`;
- реализована главная страница со списком карточек;
- реализован переход на страницу выбранной карточки;
- добавлена кнопка возврата на главную страницу;
- компоненты принимают данные через параметры и отвечают за собственную отрисовку;
- 3D-галерея кораблей перенесена в папку `3d_gallery` внутри данной лабораторной.

## Структура

- `main.js` — инициализация компонентного приложения;
- `pages/main/index.js` — главная страница;
- `pages/product/index.js` — страница выбранной карточки;
- `components/product-card/index.js` — карточка в списке;
- `components/product/index.js` — детальное отображение карточки;
- `components/back-button/index.js` — кнопка возврата;
- `3d_gallery/gallery.html` — страница 3D-галереи кораблей;
- `3d_gallery/gallery.js` — логика карточек и предпросмотра 3D-моделей;
- `3d_gallery/model-detail.html` — детальный просмотр выбранной 3D-модели;
- `3d_gallery/model-detail.js` — логика детального просмотра 3D-модели;
- `3d_gallery/idb.js` — работа с IndexedDB для пользовательских моделей;
- `3d_gallery/site.css` — оформление 3D-галереи.

## Проверка

Компонентную часть можно подключать через HTML-страницу с контейнером `root` и модулем `main.js`.

3D-галерею можно открыть через локальный статический сервер из папки `lab3/3d_gallery`:

```bash
python3 -m http.server 8004
```

После запуска страница доступна по адресу:

```text
http://localhost:8004/gallery.html
```
